# Automation Tool (Windows)

This tool is designed to run easily on Windows.

## 🚀 Setup (Do this once)
1. Double-click `install.bat`.
2. Wait for it to finish (it will prepare everything for you).
3. Once it says "Setup complete", you can close the window.

## ▶️ Running the Tool
1. Double-click `run.bat`.
2. The automation will start!

## 💡 Pro tip
- You can right-click `run.bat` and select **Send to -> Desktop (create shortcut)**.
- Rename that shortcut to "Start Automation" and use it from your desktop anytime!
